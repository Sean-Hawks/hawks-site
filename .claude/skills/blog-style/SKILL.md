# Hawks 部落格：排版與風格指南

這份 skill 是把「你（Hawks）」跟你欣賞的 **毛哥EM 資訊密技（emtech.cc）** 做對照後整理出來的。
目的不是要你變成毛哥，而是保留你的聲音，同時補上他在**排版**和**風格結構**上比較成熟的習慣。

參考樣本：
- 你：`content/posts/`（SITCON 2026、first-web…）、`content/talks/`（雜談）
- 毛哥：emtech.cc 的 `p/utfg2026`（獸聚心得）、`p/git-reword`（技術短文）

---

## 你的風格 DNA（要保留，不要改掉）

這些是你的辨識度，值得留著：

- **真誠、日記式的意識流** —「又又又遲到」「你也可以當作只是藉口」
- **自嘲式幽默** — XD、:D、注音「R」，坦白說「我現在知道我更沒有興趣了 :D」
- **對自己誠實** — 會寫焦慮、拉了的段考、遲到，不粉飾
- **署名收尾** — `-Hawks` 是個有記憶點的小簽名，留著

原則：**改結構、改排版，不要改人味。**

## 排版對照：你 vs 毛哥EM

| 面向 | 你目前 | 毛哥EM | 建議 |
|---|---|---|---|
| **開頭** | 直接進入意識流，沒有摘要 | 開頭一句 TL;DR / 一段話講清楚「這篇在幹嘛、為什麼你該讀」 | 每篇加一句開場定位，給讀者一個留下的理由 |
| **段落** | 常常一大段一路寫到底、少斷行 | 中短段落，偶爾用一句短句收尾製造節奏（「那種感覺很奇妙。」） | 一個念頭一段；適時單獨拉一句出來當節拍 |
| **完成度** | 很多是骨架 / 草稿（空標題、`## Day 0` 底下空白、`待補心得`） | 每篇自成完整，發出來就是完成品 | draft 就留 draft；要 publish 前把空段補完或砍掉 |
| **強調** | 幾乎不用粗體 / callout | 粗體標關鍵詞、blockquote 放定義（如「展後憂鬱」） | 關鍵詞用 `**粗體**`，名詞解釋用 `>` blockquote |
| **程式碼** | 隨筆少用；有用時較隨意 | code block 標語言、附 copy，前後夾解說，不堆一大塊 | 用 ```` ```bash ````，一段 code 配一句「這行在做什麼」 |
| **圖片** | Obsidian `![[a.jpg]]![[b.jpg]]` 有時兩張黏一起、無說明 | 圖片分散在敘事脈絡裡、有簡短說明 | 一張圖配一句 caption；別把圖擠成一排 |
| **導覽** | 無目錄 | 長文有 table of contents | 超過 4 個 H2 的長文考慮加目錄 |
| **收尾** | 常戛然而止 | 明確收束：感謝 / 反思 / 結論 | 結尾給一句總結或感受，再接 `-Hawks` |

## 風格對照：你 vs 毛哥EM

兩個人**都很 casual**，差別在「編輯過的 casual」vs「未修的即時 casual」：

- **毛哥＝編輯過的口語**：口氣輕鬆但每篇修過，情緒（脆弱、自嘲）是刻意安排的節拍，
  幽默多用**括號吐槽**「(不對沒有，訊號干擾很可惡)」而不是 emoji/顏文字。
- **你＝即時的口語**：像剛發生完馬上打的，XD / :D / R 直接上。真但有時鬆散、沒收束。

可以借的兩招（不會失去人味）：

1. **讀者導向**：毛哥連純心得都會讓讀者「帶走一點東西」。你可以在純紀錄裡，
   偶爾補一句「對之後想做 X 的人，這段可能有用」。
2. **把顏文字升級成吐槽**：`:D` 可以有，但關鍵笑點試著改成**括號內的一句自嘲**，
   句子會更有你、也更耐讀。emoji 當調味，別當主力。

## 寫 / 改一篇 post 前的 checklist

- [ ] 開頭有一句話說清楚「這篇在講什麼、讀者為何該看」
- [ ] 標題與 frontmatter `desc` 有填（別留空）
- [ ] 沒有空的 `## Day X` / 空 section；要嘛補、要嘛砍
- [ ] 大段落拆開；至少一處用短句收尾當節拍
- [ ] 關鍵詞 `**粗體**`；名詞解釋用 `>` blockquote
- [ ] 圖片一張一句 caption，別黏成排；確認 `![[...]]` 在網站能正確 render
- [ ] code 有標語言、前後有解說
- [ ] 結尾有收束（感受 / 總結 / 帶走的東西）＋ `-Hawks`
- [ ] 保留你的自嘲與真誠——這是你贏過教學文的地方

## 一句話總結

> 毛哥贏在**排版與收束**（讀者導向、每篇完整）；你贏在**真誠與即時感**。
> 把他的「開場 TL;DR + 段落節奏 + 明確收尾」裝進你的聲音裡，就對了。
