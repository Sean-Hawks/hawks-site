## HiPAC 是什麼？

:::info
HiPAC 是國研院國家高速網路與計算中心舉辦的「國網盃應用程式效能優化競賽」，核心是高效能計算（HPC）、平行運算與程式效能優化。2026 年的實體決賽於 8 月 4 日至 6 日在台南舉行，更多資訊可以參考 [HiPAC 2026 官方網站](https://event1.nchc.org.tw/2026/hipac/)。
:::

第一天一大早公布了題目的細項，分為五道題目，分別是效能調校、量子機器學習、Quantum ESPRESSO、大型語言模型、計算流體力學。

而我很直覺地就選擇了計算流體力學，它的全名是 Physics-Informed Neural Network Lid-driven Cavity Flow。因為前陣子一直在努力補機器學習的東西，想說會比較拿手一點。

:::info
這題通常會簡稱 **PINNs／CFD**：用 Physics-Informed Neural Networks（物理資訊神經網路）處理計算流體力學問題。文中的 **Quantum ESPRESSO** 則是一套用於第一性原理材料模擬的開源軟體。
:::

一開始我就直接開 Claude Code 幫我架起環境。基本上只要給它那些簡報資源，還有自己的一些基本常識，環境其實並不複雜。順道一提，這次國網中心給了我們一組兩台的 H200 節點，一台總共有八張，所以其實是 16 張 GPU 的資源和 2 TB 的記憶體。對，不是 SSD，是記憶體。基本上是這一生可以打到最富裕的仗了（x

![[Pasted image 20260902013202.png|主機配置]]

不過雖然說環境並不複雜，但是隊友們看起來搞了快一個小時才搞清楚，好像是沒辦法用 VS Code 的關係。我平常都用 CLI，所以比較沒有這個問題，導致一開始只有我開始在跑 Agent。

可以想像，基本上比賽的流程就是人類稍微讀了一下簡報和大概要做的事情，把想法告訴 Claude 之後讓它 cook。基本上就是一個瘋狂跟 LLM 交流的過程，所以有時候看它會挺無力的。其實技巧就是能夠告訴 Agent 要達成的目標以及目前的狀態，剩下的就是直接在 SSH 裡面開 auto。目前看起來沒有 Agent 突然搞事的狀況。

順道一提，在會場主辦方基本上就跟黑客松一樣，我們的嘴巴是不會停的。印象中給了我們各種飲料、便當、點心等等。尤其是乖乖，基本上每組桌上都有十包，可能是要我們乖一點，不要隨便動國網的機器。

不過好像效果沒有很顯著。我的隊友 Justin 在第一、二天的時候就發現能夠下載別組上傳的程式，甚至可以直接抓到最後一天才公布的隱藏題。

> 免責聲明：我們只有注意到這個狀況，沒有留存檔案，並且在第一時間回報給主辦方。

值得注意的是過夜 Job 的部分。因為國網中心不讓我們在回飯店的時候繼續 SSH 進機器，但是機器不會關，所以有辦法在裡面跑一些想要放整個晚上的 Jobs。畢竟這些題目動不動就要你訓練或跑四、五個小時，所以放過夜 Job 是很重要的。

:::info
官方把這段時間稱為 **非正規時段（Unattended Time）**：會場網路連線會關閉，也不提供設備故障排除，但設備會繼續運作，參賽隊伍可以事先安排運算工作。詳細規則可以參考 [HiPAC 2026 競賽說明](https://event1.nchc.org.tw/2026/hipac/details.html)。
:::

甚至在最後還意識到，其實可以在機器上直接放一個 Claude Code 給它跑，甚至可以遠端控制。不過很害怕會被直接禁賽，所以我們最後沒有這樣做（主要是主辦方也沒有明確禁止，所以我們也很慌）。

第二天白天並沒有拍什麼照片，因為其實開始緊張起來了，突然發現時間並沒有那麼充裕。整理好過夜 Job 之後開始有一點進度，我的 CFD 從第一天開始就一路第一名到第三天，所以其實開始在幫忙隊友。突然發現其他題目比較落後，最後有弄的是 Quantum ESPRESSO、大型語言模型和一點量子機器學習。

比較特別的是 Quantum ESPRESSO 一度被裁判關懷，因為成績似乎是最低的，有點淒慘。所以印象中第二天都在處理這一題，幸好在第二天快結束的時候找到很精妙的辦法，發現網路傳輸的瓶頸，並直接修改運作邏輯，成功衝到全場第一。

在第二天半夜的時候，幾乎是最痛苦的時段。我很害怕隔天的簡報做不完，因為第三天早上還有一道隱藏題，時間非常非常緊迫，導致幾乎沒辦法在會場準備簡報。而隊友都睡了，只剩我和伊藤兩個人在飯店樓下努力趕簡報，差點直接通宵。

## Day 3

第三天只能說非常地慌，從早上一路緊張到中午，從忙隱藏題、做簡報到上台。其實這邊我認為 HiPAC 有點處理得不太好的地方，是我們是第三個上台，而簡報截止到上台大概只有不到 20 分鐘的休息時間，幾乎也沒有什麼吃飯的時間，整個搞得很趕，也沒有時間去潤稿，導致我們出了一個大包。

到了台上，我預計要講 Quantum ESPRESSO 和 CFD，而前面的隊友講的是量子機器學習。出的問題是，在隊友只講一題的情況下，總共九分鐘就講了七分半，又講得沒有很好，導致後面兩題我只剩一分半。而這件事是在響一分鐘鈴的時候我才注意到，導致幾乎沒有什麼東西有講到，Q&A 的部分也很尷尬。

一方面覺得很生氣，為什麼不在前一天晚上好好準備，今天要搞這齣；一方面又覺得我應該要冷靜下來，畢竟過都過了。到最後實際上我也沒有做出什麼事情，基本上就吞了下去，當作部落格題材。

到頒獎典禮，我們很有自信地覺得佳作以上應該沒問題，不知道能不能撈到前三。能這樣想是因為有幾題我們拿到了很不錯的成績，但是最重要的報告部分，十分裡面大概只能拿到一、兩分，真的是非常非常可惜。

最後我們上台了三次！拿到了佳作、NVIDIA 特別獎和未來之星獎。雖然沒有成功擠進前三，不過也很高興可以一次拿到那麼多獎項。以狹義而言，我們拿到的總額甚至比第一名多。感覺評審特別喜歡高中隊（？

:::info
官方獎項名稱是 **NVIDIA CUDA—X 卓越應用獎**。我們另外拿到的「未來之星」是國網中心計算資源額度；因此雖然把獎金、Credits 和資源額度按面額相加會比冠軍獎金高，但後兩項並不是現金。完整內容可以查看 [HiPAC 2026 官方得獎名單](https://event1.nchc.org.tw/2026/hipac/news/6)。
:::
